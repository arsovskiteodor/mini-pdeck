# ADR-0004: Display: 0.96" 128×64 SSD1306, I2C-only, 4-pin

- **Status:** Accepted
- **Date:** 2026-10-28
- **Step:** 01 Lock the spec

## Context
A small display for the current layer and status. It should use few GPIO, be well supported in
QMK, run at 3.3 V and be cheap enough to have spares (the glass cracks easily).

## Options considered
| Option | For | Against |
|---|---|---|
| Waveshare 0.96" OLED (B), Diotronic MDIO9092, €8.29 | Documented pinout | Ships in **4-wire SPI** mode (I2C needs a resistor moved); 8 pins; 33 × 33.5 mm |
| Velleman VMA438, Diotronic, €18.45 | Good spec, I2C, 27 × 27 mm | About 3× the price of generics |
| AZ-Delivery 3-pack, €15.99 | Known seller, documented | Pricier than the chosen pack |
| **QWORK 3-pack, Amazon, €10.55** | SSD1306, I2C-only, 4 pins, 3 units | Only 3 ratings; listing doesn't state the voltage; contradicts itself on colour |

## Decision
QWORK 0.96" 128×64 SSD1306, I2C, 4-pin, pack of 3, from Amazon.

## Consequences
- Uses 2 GPIO on a valid RP2040 I2C pair (STATUS Q2).
- The listing gives the pin order VCC, GND, SCL, SDA. **Verify the labels printed on the received module.** Some modules put GND first.
- Confirm it works at 3.3 V on the breadboard.
- Add footprints for optional 4.7 kΩ pull-ups on SDA and SCL, not fitted by default (STATUS Q3).
- QMK needs the RP2040 I2C driver enabled for the OLED.

## Revisit if
- It doesn't work at 3.3 V, or modules in the pack differ.
