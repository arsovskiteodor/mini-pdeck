### Found / learned
- **GitHub contribution graph:** commits count only on the default branch (`main` here), and private-repo
  commits only show with "Private contributions" enabled. So none of this work shows until `dev` → `main`.
- **One email, one GitHub account.** Adding an address that another account holds fails with "email is
  already in use". A verification link opens in whichever account the browser is logged into: verify in a
  private window logged into the right account.
- **Licences of copied library files** (read 2026-11-17, sources in ADR-0014):
  - SnapMagic symbols and footprints: CC BY-SA 4.0 with SnapMagic Design Exception 1.0. Attribution is
    required when the files are shared; designs that use them may take any licence.
  - KiCad stock libraries: CC BY-SA 4.0 with an exception waiving share-alike for designs that use them
    (https://www.kicad.org/libraries/license/).
  - `siderakb/key-switches.pretty`: CERN-OHL-P-2.0 (GitHub licence API).
  - QMK: "GPL2+", keyboard code must be GPL-compatible (https://docs.qmk.fm/pr_checklist).
