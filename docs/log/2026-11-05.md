### Found / learned
- **Correction to [2026-11-04](2026-11-04.md), Session 2:** the Rev A Gerber candidate is `a389c1f`, not `6720317`.
  `6720317` and `fa31b4e` are both from 2026-11-04, after the 2026-11-03 order (see Done).
- `hardware/kicad/production/` is gitignored (`.gitignore` line 16), so the zip sent to PCBWay exists only on this
  disk.
- `main` (`30ef314`, "initial commit") does not contain the project history. PR #2 was merged into `parts`. Whether
  that is intended is not recorded.
- **Two forms of the I2C address:** the module prints the 8-bit write address (0x78). Arduino and QMK use the 7-bit
  one: 0x78 / 2 = **0x3C**.
- **Arduino's Wire hides missing pull-ups:** `Wire.begin()` turns on the AVR's internal pull-ups (ArduinoCore-avr
  `twi.c`, `twi_init`: "activate internal pullups for twi"). An OLED test with the defaults says nothing about Q3.
  Run 2 turned them off for that reason.
- **The EC11 pins are flat:** what must pass a round drill is the blade diagonal, √(width² + thickness²), not a
  "diameter".
- **Frame rate:** a full 128×64 frame is 1024 bytes. At 400 kHz I2C with 9 bits per byte, that is about 23 ms
  (calculation, not measured), which caps the rate near 40 fps before any drawing time.
- **Pro Micro uploads:** the IDE opens the port at 1200 baud to restart the board into its bootloader. If the
  running sketch can't do that, double-tap reset (RST to GND twice) starts the bootloader for about 8 s.
